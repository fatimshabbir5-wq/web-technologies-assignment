Lecture 07

CSS Positioning and Stacking

This lecture explains how CSS positioning controls the location of elements on a webpage.

Lecture Summary

Elements normally follow the document flow. CSS positioning can change their location using different position values and offset properties.

The z-index property can be used to control the stacking order of overlapping elements.

Key Concepts

  • Normal Document Flow
  • Static Positioning
  • Relative Positioning
  • Absolute Positioning
  • Fixed Positioning
  • Sticky Positioning
  • Offset Properties
  • Containing Block
  • z-index
  • Stacking Contexts
  • Floats
  • Clearing
  • Common Layout Problems

Quick Review

CSS positioning provides control over where elements appear. Relative, absolute, fixed and sticky positioning are commonly used for different layout requirements.
