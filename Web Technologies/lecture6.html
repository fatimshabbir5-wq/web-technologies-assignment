Lecture 06

The CSS Box Model and Display

The CSS box model explains how the size and spacing of HTML elements are handled on a webpage.

Lecture Summary

Every HTML element can be understood as a box containing content, padding, border and margin.

CSS display properties control how elements are placed and how they behave in the page layout.

Key Concepts

  • Content
  • Padding
  • Border
  • Margin
  • Margin Collapsing
  • box-sizing
  • content-box
  • border-box
  • Width and Height
  • Min and Max Constraints
  • Overflow
  • display: block
  • display: inline
  • display: inline-block
  • display: none
  • Borders and Shadows

Quick Review

The box model is important for understanding spacing and sizing in CSS. The display property determines how an element behaves within the layout.
