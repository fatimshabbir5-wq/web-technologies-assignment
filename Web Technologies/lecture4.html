Lecture 04

Semantic HTML and HTML Forms

This lecture explains semantic HTML elements and the basic structure and validation of HTML forms.

Lecture Summary

HTML elements can be block-level or inline. Semantic elements give meaningful information about the purpose of different parts of a webpage.

HTML forms are used to collect information from users. Different input types and validation attributes can help create useful and user-friendly forms.

Key Concepts

  • Block-level Elements
  • Inline Elements
  • div and span
  • header
  • nav
  • main
  • section
  • article
  • aside
  • footer
  • Accessibility and SEO
  • HTML Forms
  • Input Types
  • select, textarea and button
  • required, pattern, min and max

Quick Review

Semantic HTML makes the structure of a webpage easier to understand. Forms provide a way for users to enter and submit information.
