Lecture 03

HTML and HTML5 Fundamentals

HTML is a markup language used to structure the content of web pages.

Lecture Summary

An HTML document contains a basic structure including DOCTYPE, head and body. HTML uses elements, tags and attributes to organize content.

HTML can be used to create headings, paragraphs, links, images, tables, lists and multimedia content.

Key Concepts

  • DOCTYPE
  • HTML Head and Body
  • Elements and Tags
  • Attributes
  • Nesting
  • Document Validation
  • Headings and Paragraphs
  • Text Formatting
  • Absolute and Relative Links
  • Images and Media
  • Tables and Lists
  • HTML5 Elements

Quick Review

HTML provides the structure of a web page. CSS is normally used to style that structure, while other technologies can provide interaction and functionality.
