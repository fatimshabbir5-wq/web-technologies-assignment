Lecture 05

Cascading Style Sheets (CSS) Fundamentals

CSS is used to control the appearance and presentation of HTML elements on a webpage.

Lecture Summary

CSS uses selectors, properties and values to style HTML content. Styles can be written inline, internally or in an external CSS file.

CSS also provides different selectors and rules that determine which styles are applied to elements.

Key Concepts

  • CSS Syntax
  • Inline CSS
  • Internal CSS
  • External CSS
  • Element Selector
  • Class Selector
  • ID Selector
  • Attribute Selector
  • Grouping Selector
  • Descendant Selector
  • Pseudo-classes
  • Pseudo-elements
  • Cascade and Specificity
  • Inheritance
  • Colour, Font and Text Properties
  • Background Properties

Quick Review

HTML provides structure while CSS provides styling. External CSS is useful because one stylesheet can be connected to multiple HTML pages.
