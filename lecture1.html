Lecture 01

Introduction to Web Development

This lecture introduces the basic concepts of web development and explains how websites work on the Internet.

Lecture Summary

Web development is the process of creating websites and web applications. A web browser sends requests to a web server and receives responses containing web resources.

The lecture also introduces important web technologies, standards and different types of web applications.

Key Concepts

  • Internet vs. Web
  • Client-server request-response model
  • URL and URI
  • HTTP and HTTPS
  • DNS
  • Hosting and Web Server
  • Web Browser
  • Web standards: W3C, WHATWG, ECMA and IETF
  • Static and Dynamic Websites
  • MPA, SPA and PWA

Quick Review

A browser works as a client. It sends a request to a web server, and the server sends a response back. HTTP and HTTPS are commonly used for communication between the client and server.
